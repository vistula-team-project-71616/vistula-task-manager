#Task Manager

**Student ID:** 71616

## Project Description

Task Manager is a simple web application for managing tasks. Users can add, edit, complete, and delete tasks. All tasks are stored in a Supabase PostgreSQL database.

##Technologies

- HTML
- CSS
- JavaScript
- Supabase PostgreSQL
- Supabase REST API
- Git and GitHub
- GitHub Pages

## Features

- Display all tasks
- Add new tasks
- Edit task titles and descriptions
- Mark tasks as completed or incomplete
- Delete tasks
- Save changes in the Supabase database
- Keep tasks after refreshing the page

## Database

The application uses a Supabase table named `tasks` with the following columns:

- `id` — task ID
- `title` — task title
- `description` — task description
- `completed` — completion status
